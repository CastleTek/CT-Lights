# CastleTek modifications

This firmware derives from WLED 16.0.0, upstream revision
`4374f013f5a287630ef33b2d14a6ff0162891bf1`.
CastleTek modified it during September and October 2026 for CastleTek RGBW v1.

Changes include the CastleTek browser interface and discovery identity;
Compatibility API paths; fixed DigQuad output and relay policy; segment/default
house layouts; safe preset renaming; effect visibility and settings presentation;
schedules and synchronization controls; guarded app update packages; release
metadata and corresponding-source links. Underlying WLED effect and lighting
engine attribution remains intact. Internal hardware identity stays
`CastleTek_WLED_Compat_DigQuad_v2v3`.

profile; it does not provide per-client authentication or firmware signatures.
